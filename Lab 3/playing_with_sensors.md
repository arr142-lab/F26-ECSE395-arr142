# Playing with Sensors

This is my second assignment working with the ESP32. In this lab, I will connect and stream data from two different sensors.

I am using PlatformIO in Visual Studio Code on Windows to upload code to the ESP32.

## Files

- `potentiometer.cpp` - code for reading the potentiometer
- `voltage.cpp` - code for converting the potentiometer reading to voltage
- `touch.cpp` - code for the touch sensor and onboard LED
